## 一、项目概述

### 1.1 项目定位

InDigiTwin-AI 是一款面向工业场景的 **WebGL 数字孪生平台**，核心能力包括：

- 3D 工业设备模型实时渲染与交互（爆炸拆解、剖切、视角漫游）
- AI 视觉缺陷检测（图片上传 / 摄像头实时推理）
- 设备数据告警管理与 3D 定位联动
- 场景工程配置（模型上传、LOD、Draco 压缩、减面）
- 系统权限管理（角色 / 权限 / 用户）
- 数据报表驾驶舱（设备健康趋势、缺陷统计、告警分析）

### 1.2 设计基准

| 项 | 值 |
|---|---|
| 画布基准尺寸 | 1920 × 1080（16:9 工业大屏） |
| 视觉风格 | 工业深色 B 端，科技感蓝绿主调 |
| 主色 | `#0F2447` 工业深蓝 |
| 强调色 | `#2196F3` 提示蓝 / `#00C853` 正常绿 / `#E53935` 告警红 / `#FFB300` 预警黄 |

## 二、技术选型

### 2.1 核心技术栈

| 层级 | 技术 | 选型理由 |
|---|---|---|
| 构建工具 | **Vite 5** | 极速冷启动 / HMR，原生 ESM，适配 R3F |

## 四、模块划分与实现思路

### 4.1 3D 数字孪生主场景（核心模块）

**功能清单**：
- GLB 工业模型加载 + 自动居中 + 自适应缩放
- 鼠标交互：旋转 / 平移 / 缩放（OrbitControls，限制 min/maxDistance）
- **爆炸拆解 / 复原**：遍历 Mesh 子部件，沿原始中心向量偏移 `EXPLODE_OFFSET = 1.8`
- 模型剖切（ClippingPlane，二期）
- 设备测点高亮 + 告警闪烁点（Html 标签 + 动画）
- 视角保存 / 自动漫游 / 重置视角
- 右侧详情面板联动：点击设备 → 展示温度 / 压力 / AI 故障概率

**关键实现**：
- `ModelExplode.tsx`：核心 3D 组件，维护 `originPositionMap` 缓存部件原始坐标，爆炸时按系数偏移，复原时回归
- `useGLTF.preload()` 预加载模型，优化首屏
- Canvas 配置：`shadows`、`dpr={[1,2]}`、`powerPreference: 'high-performance'`、`antialias: true`
- 相机初始位置 `[5, 5, 5]`，fov 50

**性能策略**：
- DPR 上限 2，避免高分屏过度渲染
- 模型 Draco 压缩 + LOD 分级
- 大模型分片加载 / InstancedMesh 优化重复部件
- 页面切换时 Canvas 不卸载（keep-alive 思路），仅切换可见性

### 4.2 AI 缺陷检测模块

**功能清单**：
- 左侧：图片上传（拖拽 / 点击）+ 摄像头实时画面 + 素材缩略图列表
- 中间：开始检测 / 清空素材 / 生成报告 / 推理模式切换
- 右侧：缺陷标注图（红色描边框 + 标签）+ 缺陷类型列表 + 置信度 + 建议处理

**实现思路**：
- 图片上传使用 antd `Upload` 组件，支持拖拽
- 摄像头调用 `navigator.mediaDevices.getUserMedia`
- AI 推理：前端调用后端推理 API（预留接口），当前阶段用 Mock 数据模拟
- 缺陷标注：Canvas 叠加层或绝对定位 div 绘制红色边框（2px）+ 标签背景 `#E53935`
- 检测流程：点击开始 → Loading 状态（1200ms 旋转动画）→ 2s 后展示结果

### 4.3 数据告警列表模块

**功能清单**：
- 顶部筛选：告警等级 / 设备类型 / 时间范围 / 搜索设备 / 导出报表
- 中间表格：告警时间 / 设备名称 / 等级 / 告警内容 / 状态 / 操作
- 右侧统计卡片：今日告警趋势图
- 操作：定位（跳转 3D 场景 + 设备高亮闪烁）/ 查看详情 / 标记已处理 / 删除

**实现思路**：
- antd `Table` 组件，行高 48px，hover 变色 `#1A3466`
- 告警等级 Tag：红（紧急）/ 黄（预警）/ 蓝（提示）/ 绿（已恢复）/ 灰（已处理）
- 定位操作：通过 Zustand 全局状态传递 `targetDeviceId`，3D 场景监听后执行镜头飞行 + 设备闪烁
- 趋势图：ECharts 折线图

### 4.4 场景工程配置模块

**功能清单**：
- 左侧：模型上传区（拖拽 GLB/glTF + 上传进度）
- 右侧：预处理配置表单（模型名称 / LOD 等级 / Draco 压缩 / 自动减面 / 碰撞体生成）
- 底部：工程列表（预览图 / 模型大小 / 更新时间 / 操作）

**实现思路**：
- 上传组件 antd `Upload.Dragger`
- 表单 antd `Form` + `Select`
- 工程列表 antd `Table`，含缩略图列
- 模型上传后生成预览缩略图（可用 Three.js 离屏渲染或后端返回）

### 4.5 系统权限管理模块

**功能清单**：
- 左侧：角色选择卡（管理员 / 工程师 / 巡检员）
- 右侧：权限配置（3D 场景 / AI 推理 / 数据导出 / 告警查看 / 系统配置 开关）
- 底部：保存配置 / 重置权限
- 右下：用户管理面板

**实现思路**：
- 角色切换 antd `Radio.Group` 或自定义卡片
- 权限开关 antd `Switch`，分组展示
- 权限数据通过 Zustand 管理，路由守卫根据权限控制页面访问

### 4.6 数据报表统计模块

**功能清单**：
- 顶部：4 个统计卡片（设备总数 / 在线率 / 今日告警 / AI 检测次数）
- 中部：设备健康趋势折线图（温度 / 压力 / 转速多曲线）
- 右侧：健康率环形图（健康率 / 预警率 / 故障率）
- 底部：缺陷类型统计柱状图（裂纹 / 锈蚀 / 形变 / 松动）

**实现思路**：
- 统计卡片：自定义 Card 组件，大数字 + 图标 + 迷你趋势条
- 图表全部 ECharts，深色主题适配
- 数据 Mock，预留 API 接口

## 八、风险与注意事项

1. **3D 性能**：工业模型面数可能很高，必须做 Draco 压缩 + LOD，否则 FPS 不达标
2. **R3F 与 antd 共存**：Canvas 内不能直接用 antd 组件（需用 Drei `Html` 包裹），注意事件隔离
3. **模型爆炸拆解**：当前方案基于 Mesh 遍历 + 位置偏移，要求模型部件有独立的 Mesh 层级；若模型是合并几何体，需先做模型拆分预处理
4. **AI 推理**：前端仅做 UI 和接口调用，推理逻辑在后端，当前阶段全 Mock
5. **实时数据**：MQTT 接入为二期，当前用 setInterval 模拟数据刷新
