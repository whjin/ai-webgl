```
中间（10%）：开始AI检测 / 清空素材 / 生成报告 / 推理模式切换
右侧（45%）：缺陷标注图 + 缺陷类型列表 + 置信度 + 建议处理 + 统计表格
```

缺陷标注框：红色描边 2px，标签背景 `#E53935`，文字 `#FFFFFF`。

#### 页面3：数据告警列表
```
顶部筛选区：告警等级 / 设备类型 / 时间范围 / 搜索设备 / 导出报表
中间：表格（告警时间 / 设备名称 / 等级 / 告警内容 / 状态 / 操作）
```

## 五、交互流程

### 5.1 主场景操作流
首页 → 点击设备 → 右侧详情面板展开 → 查看测点数据与AI分析

### 5.2 AI检测流
AI检测页 → 上传图片/开启摄像头 → 点击开始检测 → Loading → 展示缺陷结果

### 5.3 告警处理流
告警列表 → 点击定位 → 跳转首页 → 3D镜头飞行到设备 → 设备红色闪烁 → 查看告警详情 → 标记已处理

### 5.4 工程配置流
工程配置页 → 上传模型 → 设置预处理参数 → 保存场景 → 工程列表更新

### 5.5 权限配置流
权限管理页 → 选择角色 → 配置权限开关 → 保存配置

## 六、3D 核心代码参考

### 6.1 模型爆炸拆解组件（ModelExplode.tsx）

核心逻辑：
- `useGLTF('/models/industrial-device.glb')` 加载模型
- `useEffect` 初始化时遍历所有 Mesh，缓存原始坐标到 `originPositionMap`
- 爆炸状态切换时，遍历 Mesh 沿原始中心向量偏移 `EXPLODE_OFFSET = 1.8`
- 复原时回归原始坐标
- `useGLTF.preload()` 预加载优化首屏

### 6.2 3D场景画布配置

```
Canvas 参数：
- shadows: true
- camera: { position: [5, 5, 5], fov: 50 }
- gl: { antialias: true, powerPreference: 'high-performance' }
- dpr: [1, 2]

控制器 OrbitControls：
- enablePan / enableZoom / enableRotate: true
- minDistance: 2
- maxDistance: 20

光照：
- ambientLight intensity: 0.6
- directionalLight position: [10, 10, 10], intensity: 0.8, castShadow
```

### 6.3 模型放置路径

```
public/models/industrial-device.glb
```
