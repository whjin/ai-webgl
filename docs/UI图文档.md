## Pixso 完成整套 UI / 交互 / 原型的整体工作流

### 阶段 1：项目搭建与样式归一
1. 创建 Pixso 项目，画布基准设为 **1920 × 1080**。
2. 建立全局样式库：颜色、字体、圆角、间距、阴影、动效。
3. 导入前面生成的 **Pixso 样式 JSON**，快速统一视觉规范。
4. 设置设计系统：主色为工业深蓝，强调色为青蓝/绿色/红/黄。

### 阶段 2：基础组件库搭建
1. 搭建公共组件：按钮、输入框、选择器、标签、表格、弹窗、加载态。
2. 搭建业务组件：设备状态卡、告警列表、数据图表、3D操作悬浮栏、AI结果面板。
3. 组件统一命名，例如：`Button / Primary`、`Tag / Alarm / Red`、`Card / DataPanel`。
4. 每个组件包含常态、悬停、点击、禁用四种状态。

### 阶段 3：页面 UI 效果图设计
按以下核心页面逐一完成：

| 页面                  | 比例 | 设计重点                                         |
| --------------------- | ---: | ------------------------------------------------ |
| 3D 数字孪生主场景首页 | 16:9 | 3D画布最大化，左侧菜单，右侧设备详情，底部状态栏 |
| AI 缺陷检测页面       | 16:9 | 图片/摄像头预览，AI检测按钮，缺陷结果面板        |
| 数据告警列表页面      | 16:9 | 表格、筛选、告警等级、定位操作                   |
| 场景工程配置页面      | 16:9 | 模型上传、LOD配置、工程列表                      |
| 系统权限管理页面      | 16:9 | 角色选择、权限开关、用户管理                     |
| 数据报表统计页面      | 16:9 | 图表、健康率、告警趋势、缺陷统计                 |

### 阶段 4：交互设计
1. 侧边栏菜单点击切换页面，过渡 **300ms**。
2. 告警列表点击定位到 3D 设备，设备红色闪烁。
3. AI 检测点击后显示 Loading，完成后刷新结果面板。
4. 右侧面板可折叠，3D 画布区域自动适配。
5. 弹窗、按钮、表格、输入框都要有明确反馈状态。

### 阶段 5：原型链路搭建
建议在 Pixso 中建立以下关键 Flow：

| 流程名称     | 页面链路                                        |
| ------------ | ----------------------------------------------- |
| 主场景操作流 | 首页 → 点击设备 → 右侧详情 → 查看测点与AI分析   |
| AI检测流     | AI检测页 → 上传图片 → 开始检测 → 查看缺陷结果   |
| 告警处理流   | 告警列表 → 定位设备 → 查看告警详情 → 标记已处理 |
| 工程配置流   | 工程配置页 → 上传模型 → 设置参数 → 保存场景     |
| 权限配置流   | 权限管理页 → 选择角色 → 配置权限 → 保存配置     |

### 阶段 6：交付物输出
最终交付应包含：

1. **完整 UI 效果图**
2. **Pixso 可编辑原型文件**
3. **设计系统 / 样式库**
4. **组件库**
5. **交互说明文档**
6. **页面跳转流程图**
7. **前端开发标注规范**
